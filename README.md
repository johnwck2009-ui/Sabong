# SABONG24 Football Scores

Football-only Telegram bot for live scores, fixtures and results.

## Commands

- `/start`
- `/live`
- `/today`
- `/help`

## Environment variables

- `TELEGRAM_SCOREBOT_TOKEN`
- `API_FOOTBALL_KEY`

The bot uses API-Football for match data. Do not commit API keys or Telegram tokens to GitHub.

No betting odds or gambling features are included.
